# NT-Armor

一个基于 Unity 的俯视角 2D 游戏原型，使用 **Sprite Stacking（精灵堆叠）** 技术实现伪 3D 渲染效果。

## 项目简介

NT-Armor 探索了一种无需 3D 模型即可实现立体视觉的渲染方案：将同一物体的多张 2D 切片沿屏幕 Y 轴依次偏移叠加，配合自定义几何着色器，制造出具有厚度感的伪 3D 外观。

## 核心功能

### 精灵堆叠渲染（Sprite Stacking）

| 文件 | 说明 |
|------|------|
| `Assets/Script/SpriteStacking.cs` | 运行时组件，驱动材质参数与 Z 排序 |
| `Assets/Shader&Mat/SpriteStacking.shader` | 自定义 Shader，使用几何着色器逐层展开精灵切片 |

- Sprite Sheet 中所有切片从左到右水平排列，宽度固定为 32px/层
- 支持最多 50 层（几何着色器输出上限 150 顶点）
- 基于物体 Y 轴坐标自动计算 Z 深度，实现正确的前后遮挡排序
- 支持指定外部排序父节点（`OrderParent`）以跟随父物体排序

### 玩家控制（PlayerController）

- **移动**：WASD / 方向键，斜向自动归一化
- **瞄准**：鼠标位置驱动躯干朝向，平面射线投影取世界坐标
- **武器旋转**：躯干转向角度误差 < 10° 时，双武器槽独立对准鼠标
- **腿部惯性**：四条腿（FL / FR / BR / BL）基于移动速度产生滞后感，停止时向前超冲后回归

### 相机控制（CameraController）

- 平滑跟随玩家位置（Lerp 插值）
- 鼠标超出阈值后，镜头向光标方向偏移，增强瞄准感
